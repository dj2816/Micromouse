# Micromouse PCB Design

KiCad PCB design files for the Micromouse project.

- `Version1/` — first hardware design version, including the schematic, PCB layout, symbols, and custom footprints.
- `Version2/` — snapshot of the KiCad design from `UCI-2026-27-Kit-Micromouse`, uploaded on 2026-11-14, including the schematic, PCB layout, project files, custom libraries, and STEP model. Version1 is preserved unchanged.
